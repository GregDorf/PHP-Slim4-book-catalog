# Задача: написать REST API "Каталог книг" на Slim 4 + PDO.  
  
− GET /books - список книг 
− GET /books/{id} - одна книга 
− POST /books - добавить книгу (валидация: название, автор, год) 
− DELETE /books/{id} - удалить 
− Middleware для логирования всех запросов 
− Миграция для создания таблицы books 
− 5+ юнит-тестов для контроллеров/сервисов 
  
Срок: до 2-ух недель 
  
Критерии: API работает, тесты проходят, код соответствует PSR-12.
